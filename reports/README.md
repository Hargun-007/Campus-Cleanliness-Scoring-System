# Reports Directory

This directory stores evaluation metrics, benchmark comparison reports, and diagnostic plots generated by the evaluation pipeline.

## Generated Reports

- **`evaluation_metrics.json`**: Precision, Recall, F1-score, mAP@0.5, and mAP@0.5:0.95 measured on the held-out test split (15%).
- **`model_comparison.json`**: Side-by-side comparison between the pretrained YOLOv8n baseline and the fine-tuned YOLOv8n model.
- **`campus_test_results.json`**: Evaluation and detection summary for real-world campus photographs (`data/campus_test`).
- **`precision_recall_curve.png` / `confusion_matrix.png`**: Ultralytics diagnostic plots from test evaluation.
- **`scoring_comparison.csv`**: Comparison between the count-only baseline score and the count-plus-area cleanliness score.
